# 采集引擎来源说明

`engine/` 包含本项目随附的采集引擎源码，来源于 NanmiCoder 的 MediaCrawler 项目。上游仓库在其 README 中将项目用途限定为个人学习与技术研究，禁止商业用途，并要求遵守法律法规和平台规则。原始 README 与代码注释随源码保留。

本桌面应用仅暴露快手任务入口，不会自动绕过登录、验证码或平台访问限制。启动任务后，请由使用者自行完成官方页面要求的登录和确认操作，并控制采集范围与频率。

随项目提供的 `tools/node.exe` 与 `tools/uv.exe` 分别保留了 Node.js 与 uv 的上游许可文本；运行环境安装后不要求系统另行安装这两个命令行工具。
